Sqoop Commands

1. List Databases

sqoop list-databases --connect jdbc:mysql://host:3306/ --username user --password pass

2. List Tables

sqoop list-tables --connect jdbc:mysql://host:3306/db --username user --password pass

3. Import Table to HDFS


sqoop import \
  --connect jdbc:mysql://host:3306/db \
  --table emp \
  --username user --password pass \
  --target-dir /data/emp

4. Import with Where Clause


sqoop import \
  --connect jdbc:mysql://host:3306/db \
  --table emp \
  --where "dept = 'IT'" \
  --username user --password pass \
  --target-dir /data/emp_it

5. Incremental Import (Append)


sqoop import \
  --connect jdbc:mysql://host:3306/db \
  --table emp \
  --incremental append \
  --check-column id \
  --last-value 100 \
  --username user --password pass \
  --target-dir /data/emp_inc

6. Export from HDFS to DB


sqoop export \
  --connect jdbc:mysql://host:3306/db \
  --table emp \
  --username user --password pass \
  --export-dir /data/emp
