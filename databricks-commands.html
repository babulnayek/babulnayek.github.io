Databricks Commands

1. Databricks CLI Authentication

databricks configure --token

2. DBFS (Databricks File System) Commands

databricks fs ls dbfs:/
databricks fs cp file.txt dbfs:/data/file.txt
databricks fs cp dbfs:/data/file.txt ./file.txt
databricks fs rm dbfs:/data/file.txt
databricks fs mkdirs dbfs:/data/newfolder

3. Workspace Commands

databricks workspace ls /Users
databricks workspace import notebook.py /Users/bharat/notebook.py
databricks workspace export /Users/bharat/notebook.py notebook.py
databricks workspace rm /Users/bharat/notebook.py

4. Cluster Commands

databricks clusters list
databricks clusters get --cluster-id 1234-567890-abcd
databricks clusters start --cluster-id 1234-567890-abcd
databricks clusters restart --cluster-id 1234-567890-abcd
databricks clusters delete --cluster-id 1234-567890-abcd

5. Jobs Commands

databricks jobs list
databricks jobs get --job-id 123
databricks jobs run-now --job-id 123
databricks jobs delete --job-id 123

6. Notebooks Commands

databricks workspace ls /Users/bharat
databricks workspace import notebook.py /Users/bharat/notebook.py
databricks workspace export /Users/bharat/notebook.py notebook.py

7. Secrets Commands

databricks secrets list-scopes
databricks secrets create-scope --scope myscope
databricks secrets put --scope myscope --key mykey
databricks secrets list --scope myscope

8. Databricks SQL Commands

databricks sql warehouses list
databricks sql warehouses start --id 1234
databricks sql warehouses stop --id 1234

9. Databricks Libraries

databricks libraries install --cluster-id 1234 --whl mylib.whl
databricks libraries uninstall --cluster-id 1234 --whl mylib.whl
