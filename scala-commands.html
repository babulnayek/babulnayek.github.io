Scala Commands

1. Start Scala REPL

scala

2. Compile Scala File

scalac MyApp.scala

3. Run Compiled Class

scala MyApp

4. SBT – Run Project

sbt run

5. SBT – Test

sbt test

6. SBT – Package JAR

sbt package

7. Basic Scala Examples


val nums = List(1,2,3)
nums.map(_ * 2)
nums.filter(_ % 2 == 0)
