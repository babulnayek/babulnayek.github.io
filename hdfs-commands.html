HDFS Commands

1. List Files & Directories

hdfs dfs -ls /
hdfs dfs -ls -R /

2. Create Directories

hdfs dfs -mkdir /data
hdfs dfs -mkdir -p /data/input/logs

3. Upload Files to HDFS

hdfs dfs -put file.txt /data/
hdfs dfs -put localfolder /data/ -f

4. Download Files from HDFS

hdfs dfs -get /data/file.txt ./
hdfs dfs -get /data/folder ./localfolder

5. Copy Files

hdfs dfs -cp /data/file.txt /backup/file.txt

6. Move Files

hdfs dfs -mv /data/file.txt /archive/file.txt

7. Remove Files & Directories

hdfs dfs -rm /data/file.txt
hdfs dfs -rm -r /data/folder
hdfs dfs -rm -skipTrash /data/file.txt

8. View File Contents

hdfs dfs -cat /data/file.txt
hdfs dfs -tail /data/file.txt
hdfs dfs -head /data/file.txt

9. File System Usage

hdfs dfs -du /data
hdfs dfs -du -h /data
hdfs dfs -count /data

10. Check File Replication

hdfs dfs -stat %r /data/file.txt

11. Change Replication Factor

hdfs dfs -setrep -w 3 /data/file.txt

12. Permissions

hdfs dfs -chmod 755 /data
hdfs dfs -chown user:group /data

13. HDFS Admin Commands

hdfs dfsadmin -report
hdfs dfsadmin -safemode get
hdfs dfsadmin -safemode enter
hdfs dfsadmin -safemode leave

14. HDFS Balancer

hdfs balancer

15. HDFS fsck (Health Check)

hdfs fsck /
hdfs fsck /data -files -blocks -locations
