AWS Glue Commands

1. List Glue Jobs

aws glue list-jobs

2. Start Glue Job

aws glue start-job-run --job-name my-glue-job

3. Get Job Run Status

aws glue get-job-run --job-name my-glue-job --run-id xyz

4. List Crawlers

aws glue list-crawlers

5. Start Crawler

aws glue start-crawler --name my-crawler
