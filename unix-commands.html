Unix Commands

1. File Listing

ls -l
ls -la

2. Change Directory

cd /path/to/dir

3. View File

cat file.txt
tail -n 50 file.txt
head -n 50 file.txt

4. Search in File

grep "error" file.txt
grep -r "pattern" /path

5. Disk Usage

df -h
du -sh /path

6. Permissions

chmod 755 script.sh
chown user:group file.txt

7. Processes

ps -ef
top
kill -9 PID
