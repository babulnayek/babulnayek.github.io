Git Troubleshooting Guide

1. Fix Merge Conflicts

git status
git add file.txt
git commit

2. Fix Detached HEAD

git checkout main

3. Undo Last Commit

git reset --soft HEAD~1

4. Undo Commit Completely

git reset --hard HEAD~1

5. Fix Wrong Branch Commit

git cherry-pick COMMIT_ID

6. Fix Wrong Push

git push --force-with-lease

7. Fix Stuck Rebase

git rebase --abort

8. Fix Stuck Merge

git merge --abort

9. Clean Untracked Files

git clean -fd

10. Fix Corrupted Repo

git fsck
git gc
