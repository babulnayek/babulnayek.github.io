Git Interview Questions

1. What is Git?

Git is a distributed version control system used to track changes in code.

2. Difference between Git and GitHub?

Git = Version control tool
GitHub = Cloud hosting platform for Git repositories

3. What is a commit?

A snapshot of your code changes.

4. What is a branch?

A parallel version of your code used for development.

5. What is merge conflict?

When two branches modify the same lines of code.

6. What is rebase?

Reapply commits on top of another base branch.

7. What is cherry-pick?

Apply a specific commit from one branch to another.

8. What is HEAD?

Pointer to the current branch reference.

9. What is .gitignore?

File that tells Git which files to ignore.

10. What is Git stash?

Temporarily save uncommitted changes.

11. What is Git reset?

Move HEAD to a previous commit (soft/mixed/hard).

12. What is Git revert?

Create a new commit that undoes a previous commit.

13. What is Git fetch?

Download changes without merging.

14. What is Git pull?

Fetch + merge.

15. What is Git push?

Upload local commits to remote repository.
