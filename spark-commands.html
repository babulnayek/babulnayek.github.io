Spark Commands

1. Start Spark Shell

spark-shell

2. Start PySpark

pyspark

3. Submit Spark Job

spark-submit --class MainApp app.jar

4. Read File

val df = spark.read.csv("file.csv")

5. Show Data

df.show()

6. Print Schema

df.printSchema()

7. Filter

df.filter($"age" > 30).show()

8. Group By

df.groupBy("dept").count().show()

9. Write Output

df.write.mode("overwrite").csv("/output")

10. Spark SQL


df.createOrReplaceTempView("emp")
spark.sql("select * from emp")
