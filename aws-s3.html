AWS S3 Commands

1. List Buckets

aws s3 ls

2. List Objects Inside a Bucket

aws s3 ls s3://my-bucket-name

3. Upload a File to S3

aws s3 cp file.txt s3://my-bucket-name/

4. Download a File from S3

aws s3 cp s3://my-bucket-name/file.txt ./

5. Upload a Folder to S3

aws s3 cp myfolder/ s3://my-bucket-name/ --recursive

6. Download a Folder from S3

aws s3 cp s3://my-bucket-name/myfolder/ ./myfolder --recursive

7. Sync Local Folder to S3

aws s3 sync ./local-folder s3://my-bucket-name/

8. Sync S3 Bucket to Local

aws s3 sync s3://my-bucket-name ./local-folder

9. Remove a File from S3

aws s3 rm s3://my-bucket-name/file.txt

10. Remove a Folder from S3

aws s3 rm s3://my-bucket-name/folder/ --recursive

11. Copy Between Two Buckets

aws s3 cp s3://source-bucket/file.txt s3://destination-bucket/

12. Sync Between Two Buckets

aws s3 sync s3://source-bucket s3://destination-bucket

13. Create a Bucket

aws s3 mb s3://my-new-bucket

14. Delete a Bucket

aws s3 rb s3://my-bucket --force

15. Enable Server-Side Encryption

aws s3 cp file.txt s3://my-bucket/ --sse AES256

16. Set ACL (Public Read)

aws s3api put-object-acl --bucket my-bucket --key file.txt --acl public-read

17. Get Object Metadata

aws s3api head-object --bucket my-bucket --key file.txt

18. List Bucket Policy

aws s3api get-bucket-policy --bucket my-bucket

19. Put Bucket Policy

aws s3api put-bucket-policy --bucket my-bucket --policy file://policy.json

20. Enable Versioning

aws s3api put-bucket-versioning --bucket my-bucket --versioning-configuration Status=Enabled
