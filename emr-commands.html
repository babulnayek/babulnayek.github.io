EMR Commands

1. List EMR Clusters

aws emr list-clusters

2. Describe Cluster

aws emr describe-cluster --cluster-id j-XXXXXXXXXXXXX

3. Add Step to Cluster


aws emr add-steps \
  --cluster-id j-XXXXXXXXXXXXX \
  --steps file://steps.json

4. Terminate Cluster

aws emr terminate-clusters --cluster-ids j-XXXXXXXXXXXXX
